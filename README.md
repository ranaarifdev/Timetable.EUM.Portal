## 🌟 Overview
A comprehensive, responsive, lightweight portal providing instant access to Fall 2026 tentative timetables for all computing departments, faculty members, and student cohorts.

### Features:
- **Teacher-Wise Timetable:** View individual teacher schedules, weekly lecture breakdown, workload count, and jump to specific days.
- **Class-Wise Timetable:** Browse by Department (CS, SE, IT, AI, Cyber Security, Data Science), Semester, and Shift with **Weekly Grid** and **Mobile-Optimized Card/List** view modes.
- **Course Details Modal:** Interactive modal popup showing Course Title, Code, Credit Hours, Theory/Lab status, Instructor, Room, Day, and Shift.
- **Schedule Explorer:** Daily and shift-wise views with current time highlighting.
- **Subjects Catalog:** Searchable catalog of all 338+ course modules across 54 class groups.
- **Rooms Matrix:** Room schedules, utilization breakdown, and lab allocations.
- **Dynamic Statistics:** Real-time metrics calculated dynamically from the 981 verified schedule entries across 54 classes (27 Morning, 27 Evening).
- **Offline / Mobile Ready:** Responsive design optimized for both mobile smartphones and desktop browsers, with print-ready styling.
