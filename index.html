How It Was Built

This portal was engineered as a high-performance, responsive academic management solution for Emerson University Multan students and faculty.

⚡ Static Architecture

Built as a static, client-side web application. No backend or database is required — fast, lightweight, and works seamlessly offline or via GitHub Pages.

📄 Official Data Extraction

Timetable data was extracted and structured directly from the official Emerson University Fall 2026 PDF timetables keeping the documents as the single source of truth.

🎨 Modern Frontend

Built with semantic HTML for structure, responsive CSS for a modern aesthetic with glassmorphism and theme controls, and vanilla JavaScript for portal functionality and data handling.

🐍 Python Pipeline

Python scripts (using PyMuPDF) were used for PDF/data extraction, table alignment, metadata processing, cross-verification, and dataset generation.

🔍 Comprehensive Views

Includes Teacher Wise, Class Wise, Today's Schedule, Subjects catalog, Room timetables, Statistics & analytics, and quick global search.

🏫 Room Availability & Print

Features real-time and slot-based room availability tracking across all 29 campus rooms and labs, alongside dedicated print-ready layout generation.
